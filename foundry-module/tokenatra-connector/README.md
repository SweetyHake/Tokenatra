# Tokenatra Connector (Foundry VTT v13/v14)

Запускает [Tokenatra](https://github.com/SweetyHake/Tokenatra) — студию токенов
с удалением фона на базе нейросети — прямо в окне Foundry.

## Возможности

- **Студия внутри Foundry** (по механизму Tokenizer 2): кнопка «Tokenatra»
  в шапке листа актёра или ПКМ по актёру → «Редактировать в Tokenatra» —
  редактор открывается сразу с артом этого актёра. Кнопка на панели токенов
  открывает пустую студию. В окне — только вкладка «Создание токена»
  (кольца, тень, цветокоррекция, ластик, пресеты).
- **Удаление фона без открытия студии**: ПКМ по актёру → «Удалить фон
  (Tokenatra)» — арт актёра заменяется вырезанной версией (обновляются
  и токены на сцене). То же — кнопка на Token HUD.
- Диалог экспорта: создать актёра / обновить текущего / скопировать путь.
  Игроки без прав загрузки получают файл локально (ничего не пишется в БД мира).

## Требования

1. **Tokenatra 26.4+** запущена на том же компьютере, что и клиент Foundry
   (пара «клиент в браузере на другой машине — не сработает»). Удобнее всего
   держать приложение свёрнутым в трей: удаление фона остаётся доступным,
   а память экономится.
2. В Tokenatra выбрана модель удаления фона (`.onnx`) в Настройках → Модель.

## Установка

1. Foundry → **Add-on Modules → Install Modules**.
2. В поле *Manifest URL* вставьте:
   ```
   https://raw.githubusercontent.com/SweetyHake/Tokenatra/main/foundry-module/tokenatra-connector/module.json
   ```
3. Включите модуль в мире.

## Как это работает

Foundry встраивает интерфейс Tokenatra (`http://127.0.0.1:7878/?embed=1`)
через iframe и общается с ним по postMessage; быстрые действия зовут HTTP API
Tokenatra напрямую (`/process`, `/health`). Сервер Tokenatra принимает запросы
только с `localhost`/`127.0.0.1` (любой порт) — наружу ничего не торчит.

## Известные ограничения

- Foundry должен открываться по `localhost`/`127.0.0.1` (не по LAN-IP и не
  через https-прокси) — политика frame-ancestors.
- Арт с внешних хостингов (S3/CDN без CORS) не читается быстрым действием —
  сохраните файл локально.
- Встраивается только UI; системные диалоги сохранения файлов заменены
  кнопкой «Отправить в Foundry».
